## Deploy on GitHub Pages

1. Create a new GitHub repository (e.g. `skillaurnob.github.io` or any name)
2. Upload all files maintaining the folder structure above
3. Go to **Settings → Pages**
4. Under **Source**, select `Deploy from a branch` → `main` → `/ (root)`
5. Save — your site will be live at `https://yourusername.github.io/reponame`

## Customize Email

In `index.html`, find `skillaurnob@gmail.com` and replace with your actual email address (appears in 2–3 places).

## Fonts

Fonts load from Google Fonts (requires internet). No extra setup needed.
